INC-01 – Manejo incorrecto de expiración de sesión

Resultado actual:
Cuando el token JWT expira, las solicitudes protegidas devuelven 401 Unauthorized; sin embargo, el frontend mantiene visible la pantalla autenticada y presenta los datos vacíos junto al mensaje “Sesión inválida o expirada”.

Resultado esperado:
Cuando el backend responda 401 debido a una sesión inválida o expirada, la aplicación debe eliminar el token almacenado, limpiar el usuario autenticado y retornar automáticamente a la pantalla de inicio de sesión.

Severidad: Media.

Prioridad: Alta, porque está relacionada con autenticación y experiencia del usuario.

solución
Se implementó un manejo centralizado de respuestas 401 Unauthorized en el frontend. Cuando la sesión expira, se elimina el token almacenado, se limpia el usuario autenticado y la aplicación redirige al inicio de sesión mostrando un mensaje informativo. Además, se diferencia este caso de un error de credenciales durante el login.
